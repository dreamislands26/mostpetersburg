# MOST Petersburg — Colour System
Status: approved direction, initial implementation tokens
Updated: 2026-11-11

## Brand palette
- Azure Blue / primary: `#39A9D2` — Neva, canals, sky, discovery
- Amber Gold / accent: `#D5A04A` — warm heritage, sunlight, architectural details
- Wet Asphalt / foundation: `#343B40` — contemporary urban identity, typography and navigation
- Warm Ivory / surface: `#F5F3ED` — calm editorial canvas

## Usage
- Approximate composition: 55% ivory, 25% asphalt, 15% azure, 5% amber. Treat as art-direction guidance, not a rigid quota.
- Use asphalt text on ivory and white text on asphalt. Azure and amber are primarily decorative/accent colors, not default small-text colors on light backgrounds.
- Reserve amber for highlights, small dividers, key illustration details, and selected emphasis.
- Maintain WCAG AA contrast for functional text and controls; use darker tonal variants for text or button labels where required.
- Keep destination artwork original and heritage photos rights-reviewed. Avoid copying Belmond artworks.
- Modern, technological Visitors Map: crisp vector layers, clear typographic hierarchy, precise route geometry; no childlike pictograms.
- Typography remains under review. Do not force a font replacement without visual testing.

## Implementation note
These are source-of-truth proposed tokens. Existing CSS remains unchanged until a cross-page visual and accessibility audit is completed.
