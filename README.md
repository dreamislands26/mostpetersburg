# MOST Petersburg

Independent destination management and marketing platform focused on international audiences visiting Saint Petersburg.

## Status
Initial English-language static landing page committed. Contact details and lead capture are intentionally not active until verified.

## Deployment
This repository is framework-free HTML and can be hosted on any commercial-permitted static hosting service. Connect the repository to a hosting project, set output directory to the repository root, and deploy `main`.

## Before going live
- Add verified business contact details and a functioning lead capture channel.
- Review travel services, permissions and legal disclosures.
- Connect mostpetersburg.ru via REG.RU DNS once hosting is selected.
- Configure HTTPS and verify the live URL.
- Add privacy notice before collecting personal data.
